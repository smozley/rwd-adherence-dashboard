# 🩺 RWD Adherence & Patient Journey Analysis

This project simulates how real-world data (RWD) can be used to assess medication adherence and patient treatment timelines, using synthetic claims and EMR data.

📊 **Live Dashboard**:  
[View on Tableau Public](https://public.tableau.com/views/RWDAdherenceDashboardSyntheticEMRClaimsData/Dashboard2)

---

## 📌 Project Goals

- Analyze synthetic patient-level data to simulate commercial pharma analytics use cases
- Track medication adherence using **Proportion of Days Covered (PDC)**
- Model patient journeys from **diagnosis to first prescription**
- Visualize patterns across **region, gender, and age group**
- Build a dashboard for **interactive stakeholder exploration**

---

## 🧪 Tools & Technologies

- **Python / Pandas**: Data wrangling, metric derivation
- **SQL logic**: Implemented in notebook for cohort creation
- **Tableau Public**: Dashboard creation and sharing

---

## ✅ Key Insights

- **~42% of patients** were **non-adherent** (PDC < 0.8)
- **Average delay to first prescription**: ~19.6 days
- **Regional and age-based variations** observed in adherence and treatment timelines
- Tableau dashboard enables filtering by **region, gender, and age group**
